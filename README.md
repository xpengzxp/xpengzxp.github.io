# xpengzxp.github.io

Personal website of **Xiaopeng Zhang**, Ph.D. student in Computer Science at Rutgers University.

Live at <https://xpengzxp.github.io/>.

Plain HTML/CSS/JS, no build step:

- `index.html` – all content (edit text here)
- `assets/css/style.css` – layout, colors, animations
- `assets/js/main.js` – smooth scroll ([Lenis](https://github.com/darkroomengineering/lenis)), scroll effects, and the cat & dog scrollbar
- `CV_Xiaopeng_Zhang.pdf` – CV linked from the page

Preview locally:

```bash
python3 -m http.server 8000
```
